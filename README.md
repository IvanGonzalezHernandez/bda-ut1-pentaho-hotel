# bda-ut1-pentaho-hotel

Práctica integradora de la UT1 (Big Data Aplicado): informe de cobros y control de reservas sin cobro de un grupo hotelero con Pentaho PDI.

- **Autor:** Iván González Hernández
- **Código asignado:** A010 (conjunto `cierre_aula_01`, paquete entregado por el profesor; ver `asignacion.json`)
- **Herramientas:** PDI Community 9.4.0.0-343, Java (pendiente de indicar versión)

## Estructura

| Carpeta | Contenido |
|---|---|
| `entrada/` | CSV originales del paquete asignado (sin modificar) |
| `procesos/` | Transformaciones (`.ktr`) y job (`.kjb`) |
| `temporal/` | Salidas provisionales (no se versiona) |
| `salida/` | Informes publicados |
| `evidencias/` | Registros de sesión, tabla de comprobación y pruebas |
